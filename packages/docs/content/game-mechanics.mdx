The simulation is a model of rail freight in the game, not a copy of it. Each
statement below says which game version it refers to and how it is known. When the
game changes, or a statement is checked more closely, this page is updated.

## Evidence levels

- **observed**: seen by playing the game and watching what happens. The most likely
  to be incomplete.
- **shadow-mode**: compared against the game by running a policy beside the game's own
  dispatch in a mod, and checking that both make the same decisions.
- **game-code**: read from the game's own code.

Nothing here is above *observed* yet. Checking the baseline in shadow mode is planned
once a mod exists.

## Lines and trains

Trains run back and forth along a line, reversing at each end and stopping at every
station on the way. A line can have more than two stations.

<Evidence level="observed" />

Storms and other disasters do not slow trains or stop them running.

<Evidence level="observed" />

## Station storage

A station stores each resource it is set up for separately. A small station holds 30
units of each enabled resource, and a large station 60.

<Evidence level="observed" />

The starter scenarios use 30-unit stations.

## Station balancing

At a stop, a train appears to load or unload each resource so that the stations on the
line hold similar amounts of it. It does not appear to take account of:

- how quickly a station's consumers use the resource, or how quickly its producers make it;
- whether a station is a source, a destination or neither;
- what other trains on the line are carrying;
- which resources matter most.

<Evidence level="observed" />

`naive.lua` and the [ops.balance](/docs/ops/balance) block implement this rule: move
each resource at the stop towards its average stock across the stations that store it.
The exact rule the game uses, including rounding and the order resources are handled
in, is not known.

## Storms

Storms change the world while they last. They can stop production of some resources, a
supply shock, and the damage they cause can raise demand for maintenance materials such
as metals, machine parts and polymers, a demand shock. Scenarios model these as
[world events](/docs/scenario-format#events).

<Evidence level="observed" />

During storms, shuttles that would otherwise carry goods are grounded, which could send
more traffic to the railway. The simulation does not model this yet.

## Numbers

Rates, train speeds, distances and dwell times in the starter scenarios are
placeholders chosen to show each failure clearly. They have not yet been matched to
typical values in the game, so compare policies with each other rather than reading the
numbers as predictions.
